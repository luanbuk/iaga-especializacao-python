# Especialização - Inteligência Artificial Generativa Aplicada

## Disciplina: Fundamentos de Python

Este repositório contém materiais e exercícios desenvolvidos durante a disciplina de **Fundamentos de Python** da Especialização em Inteligência Artificial Generativa Aplicada.

### Conteúdo

Este repositório foi criado como parte do curso de Especialização em Inteligência Artificial Generativa Aplicada, com foco na disciplina de Fundamentos de Python. Ele inclui:

- Materiais didáticos
- Exercícios práticos
- Projetos de implementação
- Documentações de sistemas de design

### Objetivo

O objetivo deste repositório é servir como material de apoio para os alunos da disciplina, proporcionando:
- Base sólida em programação Python
- Aplicação prática dos conceitos aprendidos
- Desenvolvimento de competências técnicas essenciais para IA generativa

### Como Utilizar

1. Clone este repositório
2. Navegue pelas pastas e arquivos
3. Execute os exemplos e exercícios propostos
4. Contribua com melhorias e correções

### Contato

Para dúvidas sobre o curso ou materiais, entre em contato com o professor responsável.
